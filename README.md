# Clear Voice

A floating purple ball for Android. Touch a text box, tap the ball, talk, tap again. Your words are cleaned up (filler words removed, mistakes fixed, punctuation added) and typed into the box.

- Listening: Android's built-in speech recognizer
- Cleanup: Gemini (free key) with a basic offline fallback
- Typing: an Accessibility service inserts the text into the focused box

## Install
Open the **Releases** page, download `app-debug.apk` from the newest build, install it, then follow the 3 steps in the app.
